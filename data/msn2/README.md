# Msn2 observations and response definitions

`cell_features.csv.gz` contains 40,458 scalar fluorescence records derived from the Hansen and O'Shea source deposit. `condition_counts.json` contains 170 binary response tables across five definitions. `primary_condition_counts.json` contains the 34 primary tables.

`thresholds.json`, `pair_results.json`, `reference_contrasts.json` and `summary.json` provide reference calculations for the full derived-data check. `constraint_reveal.json` contains descriptive pairing-restoration results. `member_provenance.json` identifies source archive members. `zero_audit.json` records the dimensions and numerical zeros in the source matrices.
