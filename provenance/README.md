# Source and result identities

`source_manifest.json` records file paths, sizes and checksums for the executable code, supplied data and source-window sensitivity record. `msn2_manifest.json` identifies the nine files used in the full Msn2 reconstruction. `msn2_source_window_sensitivity.json` records the independent check of alternative readings of the source maximum window. The artifact manifest records generated file identities.

The biological sources and measurement definitions are described in [Data provenance](../docs/DATA_PROVENANCE.md). Model parameters are recorded in each example's `parameters_used.json`.
